# YouTube Comment Blocker

YouTubeのコメントを、ユーザー名やNGワードで非表示にできる Chrome 拡張機能です。

## 主な機能

- 🚫 コメント欄からワンクリックでユーザーをブロック
- 📝 NGワードによるコメント非表示
- 📁 CSVインポート / エクスポート対応

## インストール方法

1. GitHubの **Code** → **Download ZIP** を選択してダウンロードします。
2. ダウンロードしたZIPファイルを展開します。
3. Chromeで `chrome://extensions/` を開きます。
4. 画面右上の **デベロッパーモード** をオンにします。
5. 左上の **パッケージ化されていない拡張機能を読み込む** をクリックします。
6. 展開したフォルダー **youtube-comment-blocker-main** を選択します。

## 使い方

### ユーザーをブロックする

YouTubeのコメント欄に表示される **🚫** アイコンをクリックすると、そのユーザーのコメントが非表示になります。

### 設定画面を開く

1. Chromeツールバーの拡張機能アイコンをクリックします。
2. **YouTube Comment Blocker** を選択します。
3. **設定** をクリックします。

### 設定画面でできること

- ブロックユーザーの追加・削除
- NGワードの追加・削除
- CSVファイルのインポート
- CSVファイルのエクスポート  
※設定画面はダークモードにできます。

## 注意事項

- 本拡張機能はコメントを削除するものではありません。
- コメントは利用者のブラウザ内でのみ非表示になります。
- YouTubeの仕様変更により、一部機能が正常に動作しなくなる場合があります。
